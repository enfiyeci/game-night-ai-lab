# Menu mockup spread (2026-09-26)

Source of the private artifact "Game Night Menus" (https://claude.ai/artifact/3VhXxtgMKnhG6LLgCtQtw7):
the first screen, finding the menu, the Company menu, the finance planner, raise/research/emergency,
sound and credits, and an endings collection, three options each.

- `art/office-era*.svg` are copies of `ui/assets/office-era*.svg` with the K2 colour tokens written in,
  so they render as plain images.
- `stills/*.jpg` are single frames from the ending films in `ui/assets/endings/clips/`.
- Numbers come from `?scenario=midEra3&seed=1`. The endings collection (3 of 11 found) is an example.
- Serve this folder over HTTP to view it (`python3 -m http.server`); the page loads `app.js`.
