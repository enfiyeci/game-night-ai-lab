# IP risk research (lane gn-ip-risk, 2026-10-27)

Copyright, trademark and App Store risk for Game Night AI Lab, mostly measured against Game Dev Tycoon
(Greenheart Games, 2012), and whether "AI Lab Tycoon" is a safe store name. Research, not legal advice.

## Answer

- **Copyright next to Game Dev Tycoon: low** for a lawsuit. Rules, the loop, eras and the genre are free to copy.
  Our art, text, characters and sounds are our own.
- **An App Store copycat complaint: medium until two screens change, then low.** The training-run builder mirrors
  Game Dev Tycoon's Development Stage dialog piece by piece, and the top HUD copies its layout and colour mapping.
- **The name "AI Lab Tycoon": high.** Four other games already use it (Steam, BT Games, out November 18, 2026; two
  Android games; one browser game). "Model Mogul" was the cleanest alternative checked; "Lab Founder" second.
- A lawyer is worth paying for one thing now: a trademark clearance search on the chosen name.

## Notable catches

- Apple added guideline 4.1(c) in November 2025: no other developer's brand or product name in an app's name or icon.
- GAME DEV TYCOON is a registered US mark (4345689, class 9, renewed 2023); no EU or UK filing turned up.
- No enforcement by Greenheart against look-alikes was found; Game Dev Tycoon itself was openly inspired by
  Kairosoft's Game Dev Story.
- Korea's Supreme Court (King v. Avocado, 2019) protected a copied combination of game components as a whole;
  ⚠️ known only from news reports.
- The phone layout lane's HUD pick "3-H1 Game Dev Tycoon top strip" carries the HUD pattern rated "change".
