# Plan 2B: the playable game (UI) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the tested sim into a playable 20-minute browser game in the owner-approved K2 look: an isometric office with seated staff, a tiny HUD, a click-the-floor first menu, Game Dev Tycoon-style decision dialogs, an animated training run, the release reveal (benchmarks, press, reactions), event cards, the constitution, the summit and President screens, and an end-of-run reveal.

**Architecture:** Plain HTML, CSS and ES modules, no build step, served statically. `ui/game.js` owns the one game state and an action queue and is the only caller of `endTurn`. Screens are small modules that render into overlay layers and dispatch queued actions. Everything that can be pure (formatting, action building, recipe previews, scenario builders) lives in `ui/logic/` and is unit-tested with `node --test`; visual correctness is checked with headless-Chrome screenshots of named debug scenarios (`?scenario=`), every one looked at before a task counts as done.

**Tech Stack:** HTML5, CSS custom properties, ES modules, inline SVG; Python 3 only for the one-off office generator; Node 22 for tests; Google Chrome headless for screenshots.

## Global Constraints

- Visual reference, binding: `docs/design/mockups/K2-gdt-polished.html` and its four PNGs (states `#menu`, `#dialog`, `#release`). Match its structure, spacing and components; spec section 7b.
- Palette tokens (verbatim, on `:root` in `ui/styles.css`): `--cream #F1E4C8`, `--paper #FFFBF1`, `--ink #2E2A2B`, `--teal #3F9C8F`, `--wood #C8864C`, `--coral #E0613B` (capability), `--sky #3F84C6` (alignment). Every colour in CSS/JS/SVG is a token or a `color-mix()` of tokens. Font: Nunito (Google Fonts), Libre Baskerville italic only for the Constitution document title.
- The main screen shows only the office and the tiny HUD; decisions open on demand. Never put an always-visible dashboard back on screen (owner ruling, `~/.claude/skills/design/TASTE.md` per-surface note).
- No information by colour alone (capability = filled coral disc, alignment = sky ring; moods have face shapes and words).
- Hidden variables are never shown as numbers during play; only the end-of-run reveal shows truths.
- Fit-to-window: the stage is designed at 1440 × 900 and scales down to any window (`document.documentElement.style.zoom = min(innerWidth/1440, innerHeight/900, 1)`, re-run on resize). No page scroll.
- `prefers-reduced-motion: reduce` shortens every animation to at most 150 ms and removes looping bob/blink.
- The sim is imported, never modified, by this plan; sim changes belong to plan 2A.
- One commit per task, staged by explicit path, trailer `Co-Authored-By: Codex (gpt-5.6-sol) <noreply@openai.com>`. `npm test` passes after every task.

// tests/ui-game.test.js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { createGame } from '../ui/game.js';
import { SCENARIOS } from '../ui/logic/scenarios.js';

test('the game queues at most two moves and ends a turn through the sim', () => {
  const g = createGame({ seed: 3 });
  assert.equal(g.movesLeft(), 2);
  assert.equal(g.addMove({ type: 'deal', supplierId: 'coreflame' }).ok, true);
  assert.equal(g.addMove({ type: 'deal', supplierId: 'coreflame' }).ok, true);
  assert.equal(g.addMove({ type: 'deal', supplierId: 'coreflame' }).ok, false);
  let seen = null;
  g.subscribe((u) => (seen = u));
  g.endTurn();
  assert.equal(g.state.turn, 1);
  assert.equal(seen.state.turn, 1);
  assert.equal(g.movesLeft(), 2);
});

test('the same seed and inputs give the same state', () => {
  const a = createGame({ seed: 9 }); a.endTurn(); a.endTurn();
  const b = createGame({ seed: 9 }); b.endTurn(); b.endTurn();
  assert.deepEqual(a.state, b.state);
});

test('every scenario builds a reachable state', () => {
  for (const [name, build] of Object.entries(SCENARIOS)) {
    const s = build(1);
    assert.equal(typeof s.turn, 'number', name);
  }
  assert.ok(SCENARIOS.release(1).models.length >= 1);
});
